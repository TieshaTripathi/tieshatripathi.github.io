# Tiesha Tripathi — Portfolio

Personal portfolio exploring technology, products, and people.

This site is a standalone static page. GitHub Pages serves `index.html` directly from the root of the `main` branch. No build service is required.

## Updating the website

Edit the portfolio in the local Codex workspace, run `python work/build_portfolio.py`, then commit and push the generated `github-pages/index.html`. Every push to the published branch updates GitHub Pages automatically.
